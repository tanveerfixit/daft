# Project Rules & Guidelines

## Git & Version Control Policy
1. **DO NOT COMMIT OR PUSH AUTOMATICALLY**:
   - The assistant must **never** run `git commit` or `git push` on its own.
   - All code edits, testing, linting, and building must remain local only.
   - Only execute `git commit` or `git push` when the user explicitly instructs: "commit", "push", or "deploy to repo".
